# BashToolbox

Colección de scripts Bash para automatizar tareas cotidianas en macOS y Linux.

La documentación completa, los requisitos y las instrucciones de instalación están en el índice: [docs/README.md](docs/README.md).

## Herramientas

- [`imgopt.sh`](docs/imgopt.sh.md): convierte y optimiza imágenes a JPEG o WebP, incluidos los HEIC/HEIF de iPhone.
- [`slugify.sh`](docs/slugify.sh.md): convierte nombres de archivo a formato slug.
